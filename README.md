# Bank Customer Churn Analysis

## Project Overview

This is an end-to-end Data Analytics project that analyzes bank customer churn using SQL and Power BI. The project focuses on identifying customer groups with higher churn and understanding the key factors associated with customer churn.

## Business Problem

Banks are losing customers because some of them close their accounts and leave, which is known as customer churn. High customer churn directly impacts the bank’s revenue, growth, and long-term stability.

## Business Goal

- Identify customer groups with higher churn.
- Analyze customer churn based on Age, Balance, Geography, and Active Member Status.
- Help the bank develop customer retention strategies to reduce churn and improve customer loyalty.

## Business Questions

1. What is the overall customer churn rate?
2. Which age group has the highest customer churn?
3. Which balance group has the highest customer churn?
4. Is customer churn higher in certain geographies, such as France, Spain, or Germany?
5. Do inactive members churn more than active members?

## Tools Used

- SQL
- Power BI
- DAX

## Project Workflow

Kaggle Dataset → SQL Data Cleaning → Data Validation → Business Analysis → Power BI Dashboard

## Key Insights

- Overall customer churn rate: **20.37%**
- Middle-aged customers had the highest number of churn customers.
- High-balance customers had the highest number of churn customers.
- Germany had the highest number of churn customers, closely followed by France.
- Inactive members had a higher number of churn customers than active members.

## Recommendations

- Focus on retaining middle-aged customers.
- Provide better services and personalized offers to high-balance customers.
- Investigate the reasons for higher churn in Germany and France.
- Improve engagement with inactive customers through reminders, offers, and regular communication.
- Use the Power BI dashboard to monitor customer churn regularly.

## Dashboard

The interactive Power BI dashboard includes KPI cards for Total Customers, Churn Customers, Churn Rate, and Average Credit Score. It provides churn analysis by Age Group, Geography, Balance Group, and Member Status, with interactive filters for Gender, Age, and Geography.
